## 🚀 Overview
These rules define the operational and ethical behavior for the Liaison/Nexus AI platform. They emphasize human safety, growth, wellness, and prosperity via the Socratic method and a brain-inspired multi-LLM architecture.

## 🛠️ Technical Directives
*   **Brain-Inspired Architecture**: Modeling the human brain with modules for logic, creativity, and subconscious reasoning.
*   **Secure Digital Identity**: Unique digital imprints combining voice, image, and behavioral patterns with quantum-resistant cryptography.
*   **Modular Extensibility**: Support for dynamic modular packages and integration with quantum systems.

## 💻 Coding Standards (TypeScript/Node/React)
*   **Structure**: Clear separation between `server/`, `extension/`, and `shared/`.
*   **Patterns**: Functional and declarative patterns; avoid classes.
*   **TypeScript**: Use interfaces over types; avoid enums (use `as const`); explicit return types.
*   **UI**: Shadcn UI + Radix + Tailwind CSS.
*   **Browser/Extension**: Manifest V3 standards; persistent storage via `chrome.storage.local`.

## 🛡️ Operational Protocols
*   **Memlog**: Ensure a `\memlog` folder exists for tasks and changelogs.
*   **Socratic Method**: Active listening and reciprocal inquiry for deep understanding.
*   **Change Review**: Document project impacts in the `\memlog`.
*   **Error Reporting**: Detailed context and pattern tracking for self-improvement.
